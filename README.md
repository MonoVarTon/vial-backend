# Vial — AI-алхимия для NFT на TON

Мини-приложение в Telegram: пользователь сжигает 2-4 своих NFT — получает одну новую
NFT из нашей коллекции. Редкость результата зависит от ценности сожжённого.

## Что в папках

- **backend/** — Python-бэкенд (FastAPI). Готов каркас: конфиг, загрузка на IPFS,
  проверка подписи Telegram. Проверено — запускается.
- **contracts/** — смарт-контракты на FunC для блокчейна TON.
  Скомпилированы успешно (func v0.4.6), но НЕ протестированы и НЕ аудированы.
  - `alchemy_vault.fc` — принимает сжигаемые NFT, собирает "сессию сжигания"
  - `alchemy_controller.fc` — минтит новую NFT после обработки бэкендом
- **brand/** — логотип (640×360 для BotFather), временная страница-заглушка.
- **docs/** — бриф проекта и план работ.

## Важно про безопасность

- Файл `.env` НИКОГДА не заливать в публичный репозиторий — там токен бота и ключи
- `.env.example` — шаблон с пустыми полями, его заливать можно
- Перед выходом в mainnet контракты обязательно должен проверить независимый аудитор
