# Alchemy Protocol — Roadmap выходного MVP (15-16 августа 2026)

Статус: рабочий план, не финальный продукт. Цель выходных — **testnet MVP**, не публичный запуск.

## Честная калибровка цели

**Что мы РЕАЛЬНО получим к воскресенью:** полный цикл "подключил кошелёк → выбрал 4 тестовые NFT → сжёг → получил новую NFT с редкостью по формуле" — работает end-to-end в TON testnet, с заглушечным (не финальным) артом.

**Что НЕ произойдёт в эти выходные — фиксирую явно, чтобы не было сюрприза в воскресенье вечером:**
- Финальный персонаж/стекольный оверлей — вместо него плейсхолдер-арт (цветная карточка + бейдж тира)
- Mainnet-деплой — только testnet
- Security-аудит контрактов — без него на mainnet нельзя, это не опция на сокращение
- Коллекция на getgems — getgems индексирует только mainnet, testnet там не появится
- Публичный доступ для реальных пользователей — тестируем сами, максимум пара друзей

## Жёсткое правило по ключам — касается вас лично

Я не запрашиваю и не могу принять мнемонику/приватный ключ кошелька ни в каком виде — ни тестового, ни боевого. Это касается и вашего личного кошелька, и бэкенд-кошелька. Я готовлю код и команды для деплоя/подписи — **подписываете и отправляете вы сами**, через свой кошелёк или локально запущенный скрипт, ключ не покидает ваше устройство. Там, где нужен деплой-скрипт (TON `blueprint`), он запускается у вас, я его только пишу.
